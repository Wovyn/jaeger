        About Jaeger

        Jaeger is a small take on Frigate: a Raspberry Pi object-recognition and notification service. Cameras capture frames, YOLOv8 detects objects, and results publish to MQTT only when the scene changes. A bounded ring buffer keeps event images, each with a JSON sidecar holding the full object detection metadata.

        Wovyn R&D project. Apache 2.0.
