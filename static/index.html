        About Jaeger

        Jaeger is an experimental project built with Meta Muse and the Muse Gadgets SDK. It was created as a much smaller version of the Frigate Open Source Project.

        Jaeger was designed to run on a Raspberry Pi, support a variety of camera devices, and perform object-recognition and notifications.

        User configurable cameras capture frames, YOLOv8 detects objects, and results publish to MQTT only when the scene changes.

        A bounded ring buffer keeps event images, each with a JSON sidecar holding the full object detection metadata.

        There is a web interface to configure and interact with the platform.
